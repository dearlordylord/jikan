# Jikan

Jikan describes timed sequences and the interactions used to run workouts.

## Language

**Workout UI model**:
A declarative description of workout settings, progress, and available interactions, reusable across terminal, web, and native interfaces. Its vocabulary includes preparation, exercise, rest, and rounds.
_Avoid_: Generic timer UI model

**Demo**:
A simple application used to demonstrate and exercise Jikan's libraries in practice.
